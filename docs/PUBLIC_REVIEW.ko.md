# 공개 전 점검 기록

점검일: 2026-09-09

- 공개 대상 소스, 문서, 설정, 노트북 및 포함된 ZIP 내부 텍스트를 검사했다. 이 보고서 추가 전 Git 등록 대상은 226개 파일이었다.
- 알려진 인증키 형식, 비밀번호·토큰 직접 대입, 개인 PC 경로, IPv4 주소, SSH 접속문 및 URL 인증정보를 검색하고 URL 호스트 목록을 확인했다.
- 실제 인증키·토큰·비밀번호 또는 개인 서버 접속 주소는 발견되지 않았다. IPv4 패턴 후보 2건은 의존성 버전 번호였다.
- 개발 기획서의 개인 PC 절대 경로 2곳을 일반 경로로 바꿨다.
- 공개 프로젝트·모델·패키지 다운로드·문서 URL은 유지했다. `HF_TOKEN` 등 환경변수 이름은 실제 비밀값이 아니다.
- 노트북의 저장된 실행 출력, 실행 횟수 및 위젯 상태가 없음을 확인했다. 모든 코드 셀의 Python 구문을 검사했다.
- `assets/images/bumper.jpg`는 사용자가 제공한 예제 사진이다. EXIF 정보는 없으며 JPEG 주석은 압축 도구 이름이다. 업로드하지 않으면 노트북에서 이 이미지를 사용하며 기본 배경 모드는 `auto`다.
- `.gitignore`에 인증서·개인키·로컬 인증 설정 제외 규칙을 추가했다. 입력, 출력, 모델 캐시, 환경변수 파일은 기존 제외 규칙을 유지한다.
- 원본 ZIP에 Git 이력이 없어 현재 점검한 파일로 새 저장소를 시작한다. 커밋 작성자 이메일에는 GitHub 비공개 대체 주소를 사용한다.

이 결과는 현재 공개 대상 파일의 정적 점검이다. 향후 추가 파일이나 노트북 실행 후 저장된 출력은 다시 점검해야 한다. 이번 작업에서 GPU 추론은 실행하지 않았다.
